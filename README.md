# JR Metal Serviços

Site institucional desenvolvido para a **JR Metal Serviços**, empresa especializada em serviços de serralheria, localizada em Joinville - SC.

O projeto foi desenvolvido com foco em apresentar a empresa de forma **moderna, profissional e objetiva**, facilitando o acesso dos clientes aos serviços e canais de contato.

## 🏗️ Sobre a empresa

A **JR Metal Serviços** atua no segmento de serralheria, oferecendo serviços personalizados de acordo com as necessidades de seus clientes.

## 🚀 Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/JR-Metal-Servicos.git
```

2. Entre na pasta do projeto:

```bash
cd JR-Metal-Servicos
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto localmente.
